# ============================================
# FLOTTE PRO v1.0 - Guide d'installation
# ============================================
#
# GUIDE DE DEPLOIEMENT POUR CLIENT
# ====================================
#
# 1. DECOMPRESSER LE FICHIER ZIP
#    - Dezippez flotte-pro.zip sur votre ordinateur
#
# 2. TRANSFERER SUR VOTRE SERVEUR
#    - Connectez-vous a votre hebergement (OVH, cPanel, etc.)
#    - Via FTP (FileZilla) ou le gestionnaire de fichiers web
#    - Uploadez TOUS les fichiers dans le dossier www/ ou public_html/
#
# 3. STRUCTURE DES FICHIERS
#    /public_html/
#      ├── login.html        (page de connexion)
#      ├── app.html          (application principale)
#      ├── manifest.json      (PWA - installable sur mobile)
#      ├── sw.js              (service worker PWA)
#      ├── icon.png           (icone application)
#      ├── .htaccess          (securite + cache)
#      ├── api/
#      │   ├── index.php      (API principale)
#      │   └── config.php     (configuration)
#      └── data/              (donnees - protege)
#          └── .htaccess      (bloque acces direct)
#
# 4. CONFIGURER (optionnel)
#    - Editez api/config.php
#    - Changez SECRET_KEY (cle securite)
#    - Changez CLIENT_NAME (nom de votre entreprise)
#
# 5. INSTALLER (premiere utilisation)
#    - Ouvrez votre navigateur
#    - Allez sur: https://votre-domaine.tn/api/index.php?action=install
#      avec POST: {"admin_name": "Votre Nom", "admin_password": "votre_mot_de_passe"}
#    - Ou via la page web: ouvrez login.html et suivez les instructions
#
# 6. SE CONNECTER
#    - Allez sur: https://votre-domaine.tn/login.html
#    - Compte admin par defaut: admin / admin123
#    - CHANGEZ LE MOT DE PASSE IMMEDIATEMENT
#
# 7. CREER LES UTILISATEURS
#    - Connectez-vous en admin
#    - Onglet "Utilisateurs" > Ajouter
#    - 3 roles: Chauffeur, Comptable, Manager, Admin
#
# 8. INSTALLER COMME APP SUR TELEPHONE (PWA)
#    - Ouvrez l'app dans Chrome (Android) ou Safari (iOS)
#    - Menu > "Ajouter a l'ecran d'accueil"
#    - L'app s'installe comme une application native
#
# ============================================
# EXIGENCES TECHNIQUES
# ============================================
# - Hebergement PHP 7.4+ (OVH mutualise convient)
# - Pas besoin de MySQL (stockage fichier JSON)
# - HTTPS recommande (certificat gratuit Let's Encrypt)
#
